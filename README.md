# uligress.me

Sitio de ung (Ulises Naranjo Gress): proyectos con carruseles de fotos del proceso. Estático (HTML, CSS, JS) con Three.js, GSAP y Lenis desde CDN; GitHub Pages en https://uligress.me.

- Contenido y fotos: edita `data.js` y pon las fotos en `photos/<proyecto>/`.
- Vista local: `python3 -m http.server` en esta carpeta.
